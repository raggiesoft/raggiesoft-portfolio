11 Live Web Properties • Multi-Framework & Vanilla Web Standards • Zero SQL Databases

Live Web Application Ecosystem

Each web property in the RaggieSoft network is built with a purposeful stack—spanning TypeScript & Angular 19, PHP 8.5 MVC, React 19 & Next.js 16, SvelteKit 2 & Svelte 5, Astro 6, Nuxt 4 & Vue 3, Web Awesome Custom Elements, and Bootstrap 5.3.8—all enforcing Section 508 / WCAG 2.1 AA accessibility in production.

Architecture & Maintainability Overview *.raggiesoft.com + michaelpragsdale.com

How 11 Web Properties Stay Clean, Fast & Maintainable

  • Subdomain Topology & Edge 301 Redirects: Properties live on first-level *.raggiesoft.com subdomains (alongside michaelpragsdale.com) under unified Cloudflare SSL/HSTS, while external domains (raggiesoftmedia.com, engineroom-records.com, fracturedprisms.com, thestardustengine.com) execute clean 301 redirects.
  • Right-Sized Consolidation vs. Decoupling: Multi-artist catalogs share a single Astro 6 codebase (engineroom.raggiesoft.com/artists/{slug}), while stateful audio playback & WebVTT captioning run in Svelte 5 (music.raggiesoft.com) and cross-origin static JSON APIs are served from backstage.raggiesoft.com to both web and native C#/.NET 10 WPF and SwiftUI apps.
  • Shared WCAG 2.1 AA Navigation Layer: A lightweight shared script and stylesheet (raggiesoft-network.js / .css) provides keyboard-accessible navigation across all properties and integrates cleanly into mobile disclosure menus.

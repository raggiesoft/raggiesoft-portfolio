10 Live Production Properties • 10 Distinct Tech Stacks • Zero SQL Attack Surface

Polyglot Production Ecosystem

Rather than relying on a single hammer for every problem, I architect specialized, decoupled web applications across Angular 19 (Zoneless Signals), PHP 8.5 MVC, SvelteKit 2 + Svelte 5 Runes, Astro 6, Nuxt 4 + Vue 3, Next.js 16 + React 19, Bootstrap 5.3.8 Static SSG, Vanilla PHP/ES2024 JS, and Visual Basic 6.0 / Win32 API + TypeScript—all operating in production without a server-side database.

Architectural Governance Note for Engineering Leaders *.raggiesoft.com + michaelpragsdale.com

How 10 Polyglot Stacks Stay Maintainable Under a Solo Systems Architect

  • Subdomain-First Topology & Edge 301 Governance: Every property lives on a first-level *.raggiesoft.com subdomain (alongside michaelpragsdale.com) to retain 18+ years of WHOIS domain authority and single-tier Cloudflare Universal SSL/HSTS coverage, while external vanity domains (raggiesoftmedia.com, engineroom-records.com, fracturedprisms.com, thestardustengine.com) execute deterministic 301 edge redirects.
  • Path-Hierarchy Consolidation vs. Standalone App Decoupling: Rather than spinning up a separate framework or fourth-level subdomain for every band on the label roster, multi-tenant artist lore dossiers are consolidated under engineroom.raggiesoft.com/artists/{band-slug} on a single Astro 6 static engine—while delegating stateful audio streaming & WebVTT lyric mastering to music.raggiesoft.com (Svelte 5 Runes PWA) and dedicating stardust.raggiesoft.com (Nuxt 4 + Vue 3) to the flagship transmedia novel & accessible fleet archive.
  • Shared Cross-Network Navigation & WCAG 2.1 AA Layer: A single CDN-hosted script and stylesheet (raggiesoft-network.js / .css) links all 10 properties omnidirectionally on desktop (including the alphabetical ⚙️ Engine Room ▾ roster dropdown) and collapses cleanly into each property’s native single-hamburger menu on mobile.
